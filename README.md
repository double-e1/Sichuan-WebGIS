# 四川省地质灾害数据管理平台

## 简介

本项目是一个基于Vue3、OpenLayers、ECharts和Turf.js的地质灾害数据管理平台，旨在通过大屏可视化的方式展示和管理四川省的地质灾害数据。平台提供多种交互功能，包括地图可视化、图层管理、测量工具、热力图等，支持地质灾害的监测和决策支持。

## 技术栈

- **前端框架**：Vue3
- **地图库**：OpenLayers（通过CDN方式导入）
- **图表库**：ECharts
- **空间分析库**：Turf.js

## 功能模块

### 1. 地图可视化

- 使用OpenLayers实例化地图对象，加载高德影像图层、路网图层及注记图层。
- 支持加载GeoJSON格式的四川省地质灾害数据，并进行聚类显示。

### 2. 地图控件与图层管理

- 实现常用地图控件：导航、缩放、鼠标位置、缩放至图层等功能。
- 提供图层管理功能，支持图层的动态切换和控制。

### 3. 地图视图飞行

- 实现地图视角的动态切换和动画效果，支持视图飞行功能。

### 4. 地图下载功能

- 支持用户保存当前地图视图，提供地图截图和下载功能。

### 5. 地图交互工具

- 封装多种画笔工具，支持点、线、多边形、矩形、圆形等绘图操作。
- 提供测距、测面积工具，支持在地图上进行空间测量。

### 6. 热力图

- 使用地质灾害数据生成热力图，对高风险区域进行可视化展示。

### 7. 点击弹窗 (Popup)

- 实现点击地图要素后弹出详细信息的功能，展示灾害体的详细属性信息。

### 8. 天气显示

- 集成高德API，通过IP解析获取用户位置信息，并显示当前天气状况。
- 提供天气按钮，点击后显示或隐藏天气信息，展示当前城市、天气情况、温度、风向和湿度等信息。

### 9.数据图表

- **灾害体类型分布**：使用ECharts展示四川省不同类型地质灾害体的分布情况，帮助用户直观了解灾害类型的多样性和空间分布特征。
- **威胁人口和财产分布**：利用ECharts图表显示各地区受地质灾害威胁的人口和财产分布，支持区域风险评估。
- **市级灾害点占比**：通过饼图展示市级范围内不同类型灾害点的比例，直观反映各市级区域的灾害状况。
- **灾害点威胁等级分布**：利用柱状图显示灾害点的威胁等级分布，帮助识别高风险区域。
- **词云图**：基于灾害相关关键词生成词云图，展示关键词的频率和重要性。

### 10.灾害点属性筛选

- 支持按城市、灾害体类型和地震烈度进行单条件或组合筛选。
- 实时显示当前筛选结果数量，并支持一键重置。

### 11.框选区域灾害统计

- 在地图上绘制多边形，统计范围内部及边界上的灾害点。
- 汇总灾害点总数、类型、地震烈度、威胁人口、威胁财产和高风险点。
- 与当前属性筛选条件联动，并支持把框选结果导出为CSV明细。

### 12.灾害点缓冲区分析

- 从地图选择单个灾害点，设置0.1至50公里缓冲半径。
- 显示缓冲区内灾害点、高风险点、威胁人口、灾害类型和缓冲区面积。
- 与属性筛选条件联动，并支持导出缓冲区内灾害点CSV明细。

### 13.空间数据质量检查

- 扫描完整GeoJSON中的空几何、越界坐标、名称编号缺失、重复编号、非法数值、负数和首尾空格。
- 显示问题类型汇总和问题记录示例，并支持导出CSV问题清单。
- 检查过程只报告问题，不会自动修改原始GeoJSON。

## 使用说明

### 环境准备

- Node.js 18或更高版本
- npm 9或更高版本

### 安装步骤

1. 安装依赖：

   ```bash
   npm install
   ```

2. 配置天气服务（可选）：

   将项目根目录中的`.env.example`复制为`.env.local`，填写自己的高德Web服务Key：

   ```text
   VITE_AMAP_KEY=你的高德Web服务Key
   ```

   `.env.local`不会提交到GitHub。未配置Key时，地图展示、查询和空间分析仍可正常使用，仅天气信息不可用。

3. 启动开发服务器：

   ```bash
   npm run dev
   ```

4. 执行自动测试：

   ```bash
   npm test
   ```

启动成功后，打开终端中显示的 `Local` 地址。开发服务器运行期间不要关闭终端。

### OpenLayers加载方式

本项目在根目录的`index.html`中加载OpenLayers脚本和样式，业务代码通过全局`ol`对象调用地图API。

### 部署

1. 构建生产环境代码：

   ```bash
   npm run build
   ```

2. 部署`dist`目录到你的Web服务器。
